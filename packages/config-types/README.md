# @armemon-library/config-types

Shared TypeScript contracts for the armemon CLI, core runtime, and plugin packages.

Shared TypeScript contracts. No runtime code.

- `TaskObject` / `TaskPhase` — the init-task schema
- `PluginManifest` — the `armemon` field in a plugin's package.json
- `RuntimePluginObject` — what a plugin's runtime export must be
- `PluginWizard` / `PluginInstallPlan` — the wizard contract
- `ArmemonAppConfig` — the shape of a scaffolded app's `armemon.config.ts`
