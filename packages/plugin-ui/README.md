# @armemon-library/ui

Config-driven theme, scaling, and typography kit for armemon-scaffolded apps.

Config-driven theme, scaling and typography: light/dark/auto mode, a brand
color, a type scale, and starter `Text` / `Button` / `Container` components.

Font scaling blends your type ramp with the OS accessibility setting
(`native` / `custom` / `both`) and re-reads the OS value when the app returns to
the foreground.

Hooks: `useTheme()`, `useScaling()`.
